Bandplaner

Your band's whole running order — rehearsals, setlists, repertoire, money — in one place you actually own.

Load it in ▸ See it on GitHub

No cloud, no subscription. docker compose up -d and it's running in about a minute.

Tonight's set

1.
rehearsals · gigs

Calendar & availability

Rehearsals, gigs and meetings in a shared calendar. Everyone marks yes / no / maybe per date, so you stop asking "who's coming Thursday?" in three group chats. Subscribe it to your phone calendar as a feed.

2.
key · bpm · charts

The repertoire, shared

Every song with its key, tempo, time signature, audio files, lyrics and charts, plus private notes per player. New songs get voted in with a thumbs up or down. Drop in an audio file and the assistant fills the metadata for you.

3.
retune · instrument change

Setlists that print per player

Build the set from the library, then each member marks their own copy — a colour here, a "capo 2" note there, an icon for the retune before the encore. Export to PDF, personalised. Link one setlist to several gigs; past shows freeze as played.

4.
slow it down · transpose

A practice player built in

Play any uploaded track at 50–150 % speed without the pitch going weird, transpose it up to an octave either way, and loop a tricky four bars by dragging across the waveform. It even reads back the tempo and key.

5.
gear · money · rooms

Equipment, finances, venues, files

Packing lists you tick off before load-in. The band's money — fees and cost shares, who's owed what, CSV out. Venues with a map, capacity and the stage notes. And a file drawer that clips a technical rider to both the venue and the gig at once.

Encore: it's yours

Bandplaner runs on hardware you control. There is no account on someone else's server, nothing to cancel, and nothing watching your data.

Free

Open source under the AGPL-3.0. No tiers, no per-seat pricing, ever.

Private

SQLite and your files stay on your machine. Optional lookups can be switched off.

Small

One container, multi-arch. An x86 box, a Synology NAS, or a Raspberry Pi 4/5.

Get it running

# two files, then start it
mkdir bandplaner && cd bandplaner
curl -fsSLO https://raw.githubusercontent.com/maxxs78/bandplaner/main/docker-compose.yml
curl -fsSL  https://raw.githubusercontent.com/maxxs78/bandplaner/main/.env.example -o .env
# set AUTH_SECRET and NEXT_PUBLIC_APP_URL in .env, then
docker compose up -d

The image is ghcr.io/maxxs78/bandplaner. Full guide with HTTPS, reverse proxy and step-by-step for Synology and Proxmox: INSTALLATION.md. There's an illustrated handbook too.
