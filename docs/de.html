Bandplaner

Die ganze Bandorganisation — Proben, Setlisten, Repertoire, Kasse — an einem Ort, der wirklich dir gehört.

Einspielen ▸ Auf GitHub ansehen

Keine Cloud, kein Abo. docker compose up -d und in rund einer Minute läuft es.

Set für heute Abend

1.
proben · auftritte

Kalender & Verfügbarkeit

Proben, Auftritte und Meetings in einem gemeinsamen Kalender. Jede:r trägt je Termin Zusage / Absage / Vielleicht ein — Schluss mit „wer kommt Donnerstag?" in drei Gruppenchats. Als Feed im Handy-Kalender abonnierbar.

2.
tonart · bpm · noten

Das Repertoire, geteilt

Jeder Song mit Tonart, Tempo, Taktart, Audiodateien, Text und Noten, dazu private Notizen je Person. Neue Songs werden per Daumen hoch/runter abgestimmt. Audiodatei reinlegen — der Anlageassistent füllt die Metadaten.

3.
umstimmen · instrumentwechsel

Setlisten, die je Person gedruckt werden

Set aus der Bibliothek bauen, dann kennzeichnet jede:r die eigene Fassung — hier eine Farbe, da „Kapo 2", ein Icon fürs Umstimmen vor der Zugabe. PDF-Export, personalisiert. Eine Setlist mit mehreren Terminen verknüpfen; vergangene Auftritte werden als gespielt eingefroren.

4.
langsamer · transponieren

Ein Übungs-Player, eingebaut

Jede hochgeladene Aufnahme mit 50–150 % Tempo bei gleicher Tonhöhe abspielen, um bis zu eine Oktave transponieren und knifflige vier Takte per Ziehen in der Wellenform loopen. Tempo und Tonart liest die App gleich mit.

5.
equipment · kasse · orte

Equipment, Finanzen, Orte, Dateien

Packlisten, die vor dem Einladen abgehakt werden. Die Bandkasse — Gagen und Kostenanteile, wer wem was schuldet, CSV raus. Orte mit Karte, Kapazität und Bühnen-Notizen. Und eine Ablage, die einen Technical Rider gleichzeitig an Ort und Termin heftet.

Zugabe: es gehört dir

Bandplaner läuft auf Hardware, die du kontrollierst. Kein Konto auf einem fremden Server, nichts zu kündigen, nichts, das deine Daten mitliest.

Kostenlos

Open Source unter der AGPL-3.0. Keine Stufen, kein Preis pro Person.

Privat

SQLite und deine Dateien bleiben auf deinem Rechner. Optionale Abfragen abschaltbar.

Klein

Ein Container, Multi-Arch. Ein x86-Rechner, eine Synology, ein Raspberry Pi 4/5.

Zum Laufen bringen

# zwei Dateien, dann starten
mkdir bandplaner && cd bandplaner
curl -fsSLO https://raw.githubusercontent.com/maxxs78/bandplaner/main/docker-compose.yml
curl -fsSL  https://raw.githubusercontent.com/maxxs78/bandplaner/main/.env.example -o .env
# AUTH_SECRET und NEXT_PUBLIC_APP_URL in .env setzen, dann
docker compose up -d

Das Image ist ghcr.io/maxxs78/bandplaner. Ausführliche Anleitung mit HTTPS, Reverse Proxy und Schritt für Schritt für Synology und Proxmox: INSTALLATION.de.md. Ein bebildertes Handbuch gibt es auch.
